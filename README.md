# Vibrómetro Virtual Movida SST+

Simulador didáctico de vibraciones ocupacionales para entrenamiento en medición mano-brazo (HAV) y cuerpo entero (WBV).

Base técnica utilizada en esta versión:
- ISO 8041-1:2017
- ISO 5349-1:2001
- ISO 5349-2:2001
- ISO 2631-1:1997 + Amd.1:2010

Incluye selección HAV/WBV, ejes X-Y-Z, ponderaciones, verificación, rangos, HOLD, memoria, A(8), operaciones combinadas y errores didácticos de colocación/montaje del acelerómetro.

Proyecto de La Movida de SST Plus — https://www.movidasst.com
